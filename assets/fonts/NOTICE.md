# Bundled fonts

Self-hosted subsets of the Google Fonts families used by ScriptForge, fetched as
WOFF2 from `fonts.gstatic.com` and referenced locally by `assets/styles/fonts.css`.

| Family | Weights | License |
|---|---|---|
| Caveat | 400, 600, 700 | SIL Open Font License 1.1 |
| Indie Flower | 400 | SIL Open Font License 1.1 |
| Kalam | 300, 400, 700 | SIL Open Font License 1.1 |
| Patrick Hand | 400 | SIL Open Font License 1.1 |
| Shadows Into Light | 400 | SIL Open Font License 1.1 |
| Inter | 400, 500, 600, 700 | SIL Open Font License 1.1 |
| JetBrains Mono | 400, 500 | SIL Open Font License 1.1 |

Only the `latin` and `latin-ext` unicode-range subsets are bundled. The full
license text is in `OFL.txt`.
