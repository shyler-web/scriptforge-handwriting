# Changelog

## [1.2.0] - 2026-11-05

### Added

- Universal `[sketch]` engine (ForgeTikZ): declarative geometry, auto-layout, obstacle-aware
  routing, physics/optics fields, CS systems, chemistry, discrete math and 3D/calculus scenes.
- MCP server for AI coding agents with note CRUD, validation and an authoring guide.
- Dependency-free notes CLI for list/read/create/update/append/delete/validate/index/guide.
- Curated style presets, with Pencil Draft using Shadows Into Light.
- 110-second captioned demo video and poster in `docs/demo/`.

### Changed

- Image Tracer is now explicitly marked **Alpha**, with clearer input guidance and a
  no-centerlines fallback.
- Project metadata, Open Graph tags, repo topics and README attribution improved.

### Verification

- `npm run verify` covers the renderer, spatial engine, sketch compiler and skill schema.
- Browser QA covers waves 1–3, mobile, style presets, sketch integration and notes.

## [1.1.0]

- Offline image tracing, render polish, GitHub Pages deployment, and license.
